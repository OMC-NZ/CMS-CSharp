# Repository instructions

- Whenever an API endpoint is added, changed, renamed, or deleted, update `README.md` in the same change.
- Document the HTTP method, route, inputs, filtering rules, response shape, and relevant status codes.
- Write all README content in English.
- Keep examples free of passwords, tokens, and other secrets.
- For Development CORS, allow only `http://localhost:3000`; do not re-add `http://127.0.0.1:3000` or `http://localhost:3001` unless the user explicitly changes this requirement.
